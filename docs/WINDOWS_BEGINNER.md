# Windows で動かす（インストール不要版）はじめての人向け

パソコンに Python を入れられない Windows で NetVision を動かすための手順です。
GitHub もコマンド操作も初めてという前提で書いてあります。

作業は2つに分かれます。

| どこで | 何をするか | 誰がやるか |
|---|---|---|
| ネットに繋がるパソコン | 配布用の ZIP を1つ作る | 作る人（1回だけ） |
| 使うパソコン（閉域） | ZIP を展開してダブルクリック | 使う人 |

使う人の側では、インストールも管理者権限も要りません。

> スタートメニューから開きたい場合は、ZIP の代わりに `NetVision-Setup.exe` も使えます。
> 方法A の手順で ZIP と一緒に落ちてきます。ダブルクリックして「次へ」を押すと入り、
> スタートメニューとデスクトップの NetVision から、アプリのウィンドウで開きます。
> 管理者権限は要りません。消すときは「設定 → アプリ」からアンインストールします。
> データ（`C:\Users\<名前>\AppData\Local\NetVision`）は消えずに残ります。

---

# 第1部　配布用の ZIP を作る（ネットに繋がるパソコンで）

この作業は1回だけです。作った ZIP を配れば、以降は配るだけで済みます。

作り方は2通りあります。作業用の端末に何を入れられるかで選んでください。

| 方法 | 必要なもの | 向いている場合 |
|---|---|---|
| A. GitHub に作らせる | ブラウザだけ | 作業用の端末に何も入れられない |
| B. Git Bash で作る | Git・Node.js・Python | 従来どおり |

---

## 方法A. GitHub に作らせる（一番手軽な入手方法）

作業用の端末には何も入れません。GitHub 側で ZIP を作らせて、ブラウザで
落とすだけです。

1. ブラウザで <https://github.com/Maguro-JP/NetVision> を開き、サインインする
2. 上の `Actions` タブを押す
3. 左の一覧から `Windows bundle` を選ぶ
4. 右にある `Run workflow` を押し、もう一度 `Run workflow` を押す
5. 5分ほど待つと一覧に行が増えるので、それを押す
6. 下のほうにある `NetVision-windows` を押すと ZIP が落ちてくる

落ちてきたファイルは ZIP が二重になっています。展開すると中にもう1つ
`NetVision-（日付）-windows.zip` があるので、それを第2部で使います。

これで作れたなら、方法B は読まなくて構いません。

---

## 方法B. Git Bash で作る

### 1-1. 道具を3つ入れる

ここだけはインストールが必要です。すべて公式サイトから入れます。

| 道具 | 入手先 | インストール時の注意 |
|---|---|---|
| Git for Windows | <https://git-scm.com/download/win> | 選択肢はすべて既定のままで構いません |
| Node.js（LTS 版） | <https://nodejs.org/> | 左側の「LTS」を選びます |
| Python 3.11 以上 | <https://www.python.org/downloads/> | 最初の画面の「Add python.exe to PATH」に必ずチェック |

3つとも「次へ」を押していけば終わります。入れ終わったらパソコンを再起動すると確実です。

### 1-2. ソースコードを取ってくる

スタートメニューで `Git Bash` と検索して開きます。黒い画面（コマンドを打つ画面）が出ます。

次の2行をコピーして貼り付け、Enter を押します。貼り付けは右クリック →
「Paste」、または Shift + Insert です。

```bash
cd ~/Desktop
git clone https://github.com/Maguro-JP/NetVision.git
```

デスクトップに `NetVision` というフォルダができれば成功です。

> GitHub のページから ZIP でも取れます（緑の `Code` ボタン → `Download ZIP`）。
> その場合は展開したフォルダへ `cd` してください。

### 1-3. ZIP を作る

同じ黒い画面で、続けて次を打ちます。

```bash
cd ~/Desktop/NetVision
./packaging/make-bundle-windows.sh
```

5〜10分ほどかかります。途中で英語の行がたくさん流れますが、エラーで止まらなければ
問題ありません。終わると次の場所にファイルができます。

```
デスクトップ\NetVision\dist\NetVision-20260810-windows.zip
```

数字の部分は作った日付です。大きさは 60MB 程度になります。

> この ZIP の中には、インストール不要版の Python も一緒に入っています。
> だから使う側のパソコンには何も入れなくて済みます。

# 第2部　使うパソコンで動かす

## 2-1. ZIP を持ち込む

USB メモリなど、その職場で許可されている方法でコピーします。
持ち込みの手続き（ウイルスチェックなど）は職場のルールに従ってください。

## 2-2. 展開する

ZIP ファイルを右クリック →「すべて展開」を選びます。

置き場所は「デスクトップ」や「ドキュメント」など、自分で書き込める場所にしてください。
`C:\Program Files` の下は書き込みが制限されているので避けます。

> ZIP をダブルクリックして開いた中身から直接起動しても動きません。
> 必ず「すべて展開」で取り出してから使ってください。

## 2-3. 起動する

展開したフォルダを開き、`NetVision.bat` をダブルクリックします。

- 数秒で NetVision のウィンドウが開きます。初回はデータの準備で少し長くかかります
- ブラウザは開きません。アドレスを入力する必要もありません

「WindowsによってPCが保護されました」と出た場合は、
「詳細情報」→「実行」を押します（社内で配布したファイルであることを確認してから）。

フォルダの中の `index.html` をダブルクリックしても動きません。
必ず `NetVision.bat` から起動してください。

## 2-4. 使い終わったら

NetVision のウィンドウ右上の × で閉じると止まります。裏で動いていたサーバーも一緒に止まります。

次に使うときは、また `NetVision.bat` をダブルクリックします。
よく使うなら、右クリック →「ショートカットの作成」でデスクトップに置くと楽です。

# 覚えておくとよいこと

## データはどこにあるか

```
C:\Users\（あなたのユーザー名）\AppData\Local\NetVision
```

このフォルダをコピーすればバックアップになります。
アプリのフォルダを新しい版に入れ替えても、データはここに残ります。

## 消したいとき

展開したフォルダを削除するだけです。データも消すなら、先に上の `NetVision` フォルダを
USB メモリなどへコピーして控えを取り、控えが開けることを確かめてから削除します。
前の版から使っている場合、データは `C:\Users\（あなたのユーザー名）\.netvision` にあります（[DATA_LOCATIONS.md](DATA_LOCATIONS.md)）。
レジストリなどは一切触っていないので、他に残るものはありません。

## 他の人に見せたいとき

既定では、自分のパソコンからしか開けません。同じ社内ネットワークの他の人からは
見えない設定です。

これは安全のためです。このソフトにはまだログイン機能がありません。機器の Config には
管理IP や SNMP のコミュニティ名が入るため、URL を知っている人が誰でも見られる状態は
避けるべきだからです。

複数人で使う段階になったら、サーバーに置いて認証をかける形にしてください。
詳しくは [INSTALL.md](INSTALL.md) の「複数人で使う場合」を見てください。

# うまくいかないとき

| 症状 | 対処 |
|---|---|
| `NetVision.bat` をダブルクリックしても何も起きない | ZIP から展開せずに開いていないか確認する。展開してから実行する |
| ウィンドウが開かない | `NetVision-console.bat` をダブルクリックし、黒い画面に出た内容を控えて連絡する。展開先が書き込めない場所（Program Files など）の可能性もあるので、デスクトップに置き直す |
| 「WebView2」が無いと言われる | Windows 10 の古い版で起きる。職場の管理者に Microsoft Edge WebView2 Runtime の導入を相談する |
| `ポートが使用中` と出る | 他のソフトが 8000 番を使っている。`NetVision.bat` を右クリック →「編集」で `-m scripts.launcher` の後ろに ` --port 9000` を足す |
| 画面は出るがデータが出ない | データの置き場所（`C:\Users\<名前>\AppData\Local\NetVision`）にある `launcher.log` を控えて連絡する |
| ウイルス対策ソフトに止められた | 職場の管理者に相談する。中身はソースコードごと開示できる |
| 第1部の `./packaging/...` で `command not found` | `cd ~/Desktop/NetVision` を先に実行したか確認する |
| 第1部で `npm: command not found` | Node.js が入っていないか、再起動していない |
| 第1部で `bad interpreter` や `^M` を含むエラー | 下の「`bad interpreter` と出る」を見る |
| 第1部で `Python が見つかりません` と出る | Python を「Add python.exe to PATH」にチェックを入れて入れ直し、Git Bash を開き直す |
| 方法A で `Run workflow` のボタンが無い | そのリポジトリへの書き込み権限が要る。持っている人に実行を頼む |

## `bad interpreter` と出る

```
./packaging/make-bundle-windows.sh: /usr/bin/env: bash^M: bad interpreter
```

改行の形式の違いです。Windows の Git は、取ってきたファイルの改行を Windows 式
（CRLF）に書き換える設定が既定で有効になっています。シェルスクリプトはこれを
受け付けません。

取り直すのが一番確実です。Git Bash で次を打ちます。

```bash
cd ~/Desktop
rm -rf NetVision
git clone https://github.com/Maguro-JP/NetVision.git
```

今の版には書き換えを止める設定が入っているので、取り直せば直ります。

消したくない場合は、改行だけ戻すこともできます。

```bash
cd ~/Desktop/NetVision
sed -i 's/\r$//' packaging/*.sh
```

## それでも解決しないとき

次の3つを控えて連絡してください。原因が絞りやすくなります。

1. どの手順で止まったか
2. 黒いウィンドウに出ている最後の数行（右クリックでコピーできます）
3. Windows のバージョン（設定 → システム → バージョン情報）
