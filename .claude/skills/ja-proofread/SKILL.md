# 日本語の精度

AI の日本語は、意味は通っても読む人が引っかかるところが決まっている。翻訳調の冗長さ、外国語の文字の混入、
英語の出だし、表記のゆれ、長い一文。どれも読む人の時間を奪い、「壊れている」ように見せる。
機械で拾えるものは機械で拾い、残りは読み直しの観点で直す。

## 決まりの出どころ

表記の決まりはユーザーのもの。優先順位は次のとおり。好みで変えない。

1. そのリポジトリの `CLAUDE.md`（散文は日本語だけ、強調の記号を使わない、結論から、など）
2. そのリポジトリの `docs/STYLE.md`（あれば）
3. `references/rules.md` のデフォルト（長音あり、開く漢字、日本語と英数字の間に半角スペース、全角括弧）

決まりにないものは、同じ文書の中で揃っていればよい。揃っていないときだけ多い方に寄せる。

## 手順

### 1. 誰が読むか、文体を決める

| 書くもの | 文体 | 形 |
|---|---|---|
| 会話の返事 | CLAUDE.md の形（結論から、〜しています、マークの4種類） | 3行で収まらなければファイルへ |
| SKILL.md、docs、README | 常体（だ・である、体言止め）。命令形の手順 | 1文1義。見出しと表 |
| 日報・週報・記録 | 常体。事実と数字 | やり取りを写さない。決めたことを書く |
| コミットメッセージ、PR の本文 | 常体。1行目は何を、本文はなぜ | 何をしたかはコードにある |
| ユーザー以外に見せる文書 | 敬体（です・ます） | 二重敬語と過剰な敬語を避ける |

### 2. 機械で見る

textlint が入っていれば自動で使う（形態素解析で、ら抜き・助詞の重複・冗長表現・弱い表現を正規表現よりまさしく拾う）。
入れるのは1回だけで、置き場所はリポジトリの外。なくても動く。

```bash
.claude/skills/ja-proofread/scripts/setup-textlint.sh     # ~/.cache/ciel-textlint に入る。1〜2分
```

```bash
.claude/skills/ja-proofread/scripts/proofread.py --diff                   # 未コミットの差分
.claude/skills/ja-proofread/scripts/proofread.py --diff origin/main..HEAD # PR の差分
.claude/skills/ja-proofread/scripts/proofread.py README.md docs/USAGE.md  # 指定したファイル
.claude/skills/ja-proofread/scripts/proofread.py --tree                   # 追跡している .md .txt .rst
echo "<返事やコミットメッセージ>" | .claude/skills/ja-proofread/scripts/proofread.py --stdin
```

| 区分 | 何 | 終了コード |
|---|---|---|
| 重大 | ハングル・中国語の文字の混入、助詞の重複、英語の出だし。壊れて見える | 1 |
| 注意 | ら抜き、二重敬語、過剰な敬語、翻訳調（〜を可能にする、〜する必要がある、〜と思われる）、勝手な訳語、矢印でつないだ羅列、体言止めの連発、文末の繰り返し、半角句読点、全角英数、長い文（120 文字超）、読点が5つ以上、文体の混在、textlint の指摘 | 0（`--strict` で 1） |
| 表記 | 開く漢字（できる、下さい、事、為）、送り仮名、ゆれ（サーバ／サーバー）、空白と括弧のゆれ。まとめて数える | 0（`--strict` で 1） |

コードブロック、表の行、`コード`、URL は見ない。英語だけの文書は英語の出だしの対象外。
意図して置いた行（字の一覧、固有名詞）は行末に `ja-proofread: ignore` を書く。

### 3. 読み直す

機械で拾えないものを、読む人の目で見る。詳しい観点と例は `references/rules.md`、直訳の癖と直し方は `references/translationese.md`。

| 観点 | 見ること |
|---|---|
| 結論の位置 | 最初の1文で答えが分かるか。前置きと言い直しは削る |
| 一文一義 | 1文に言いたいことが1つか。「〜が、〜」でつなげていないか |
| 主語 | 誰が・何が、が抜けて曖昧になっていないか。省くなら文脈で一意か |
| 指示語 | 「それ」「これ」「この件」が何を指すか、読む人に分かるか |
| 同音異義語 | 以外/意外、保証/保障/補償、対象/対称/対照、制作/製作、的確/適格、回答/解答。変換の誤りは機械で拾えない |
| カタカナ語 | 日本語で言えるものを英語のまま書いていないか（イシュー→課題、フィックス→直す）。固有名詞と識別子は原文 |
| 翻訳調 | 「〜することができます」「〜を行う」「〜という」「〜において」「非常に」。短い言い方に |
| 箇条書き | 各項目の形が揃っているか（全部が名詞、全部が動詞） |
| 数字と単位 | 半角、桁区切り、単位の表記が揃っているか |
| 見出しと本文 | 見出しが本文の内容を言い当てているか |
| 文体 | 敬体と常体が混ざっていないか。会話は CLAUDE.md の形 |
| 直訳の語順 | 「〜のために、〜する」「〜を可能にする」「〜することが推奨される」のような英語の骨組みが残っていないか。条件と理由は先、結論は後 |
| 記号 | 矢印、コロン、スラッシュ、括弧で語を並べて文の代わりにしていないか。表の中はよいが、文の中では文にする |

### 4. 直す

- 最小の直し。意味を変えない。言い換えて意味がずれるなら、元のままにして `❔` で聞く
- コード、識別子、ファイル名、コマンド、設定のキー、ツール名、エラーメッセージ、引用の原文は触らない
- 自分が書いた文を直すときは、「なぜ引っかかるか」が言えるものだけ直す。好みで書き換えない
- 他人が書いた文を直すときは、決まり（1〜3）に反するものだけ。文体の癖は残す
- ユーザーの文は、頼まれたときだけ直す

### 5. もう一度見て、報告する

直したあと `--diff` をもう一度回す。報告は直した種類と数で、1行。

```
★ 校正 docs/USAGE.md: 重大 1（文字の混入）、注意 4（翻訳調 3、ら抜き 1）、表記 6 を直した。意味は変えていない
```

3行を超える説明は Markdown のファイルに書く。直していないもの（意味がずれそうで聞くもの）は `❔` で1行。

## 会話の返事の形

会話の返事、コミットメッセージ、PR の本文、`lessons` の記録も文章。出す前に `--stdin` に通すか、
3 の観点で読み直す。`lang-check.sh`（Stop フック）が会話の外国語の文字と英語の出だしを止めるが、
翻訳調と長さは止めない。

マーク（★ ↩ ❕ ❔）の後ろも、です・ますの文で書く。1行でも、主語と述語があり、助詞を省かない。

| 前 | 後 |
|---|---|
| ★ PR #61: マージ済み。CI 緑。 | ★ PR #61 をマージしました。CI は緑です。 |
| ↩ 範囲: public 限定 → private から | ↩ 範囲について、public 限定だったものを private の段階から見る形に直しました。 |
| ❕ 片付け: Routine 7件 消した | ❕ 実行済みの Routine を 7 件消しました。 |
| ❔ `**` 161 箇所: 文書にも当てるか | ❔ 文書の中の `**` 161 箇所も、応答と同じ決まりで消しますか。 |

## 英語を日本語にするとき

英語の資料、エラーメッセージの説明、他のセッションからの連絡を日本語で伝えるときは、語を置き換えるのではなく、
意味を取ってから日本語で言い直す。手順と例は `references/translationese.md` の「英語を日本語にするとき」。
固有名詞、コマンド、設定のキー、エラーメッセージの原文は訳さずそのまま。用語は `references/glossary.md`。

## やらないこと

- 意味を変えること。推測で補うこと
- 専門用語、識別子、英語の原文を訳すこと
- 全部を書き直すこと。直すのは引っかかるところだけ
- 決まりにない表記を自分の好みで変えること
- 機械が通ったことを理由に読み直しを省くこと。同音異義語と主語の欠落は機械では拾えない
- 英語の文章の校正、翻訳

## 他のスキルとの関係

- 中身（機密、個人情報、不快な表現）: `content-audit`。中身はあちら、言い方はこちら
- 会話の形（マークの4種類、3行、ファイルへ）: `work-style` の「会話に出すもの」
- 記録の書き方: `lessons`（4行の形）、`dev-report`
- 決まりのデフォルト、言い換え表、同音異義語、開く漢字の一覧: `references/rules.md`
- 直訳の癖と直し方、会話の返事の形、英語を日本語にする手順: `references/translationese.md`
- 使う語と使わない訳語: `references/glossary.md`
- textlint の設定: `assets/textlintrc.json`。入れ方: `scripts/setup-textlint.sh`
