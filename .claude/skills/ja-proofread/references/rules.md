## 表記のデフォルト

| 項目 | デフォルト | 理由 |
|---|---|---|
| 長音 | 付ける（サーバー、ユーザー、フォルダー） | 内閣告示とおもな日本語スタイルガイドが長音あり。1文書で揃っていれば逆でもよい |
| 日本語と英数字の間 | 半角スペース1つ（PR を作る、3 件） | 読みやすさ。1文書で揃える |
| 括弧 | 日本語の中は全角（）。コードの中は半角 | 日本語の文字幅に合う |
| 句読点 | 、。 | 半角 , . は日本語に混ぜない |
| 英数字 | 半角 | 全角英数は検索に引っかからない |
| 数字 | 半角。桁区切りは3桁ごとに , | |
| 強調 | 記号で強調しない | 見出しか文の構造で示す |
| 文体 | 文書は常体、ユーザー以外に見せるものは敬体。混ぜない | |
| 一文の長さ | 60 文字前後まで。120 文字を超えたら分ける | |
| 読点 | 1文に4つまで | 多ければ文を分ける |
| 箇条書き | 項目の形を揃える。文末の句点は付けるか付けないかを揃える | |

## 開く漢字

補助動詞、形式名詞、副詞、接続詞はひらがなにする。本動詞・本来の名詞は漢字のまま。

| 開く | 例 | 漢字のまま |
|---|---|---|
| できる | 確認できる | 出来事、出来高 |
| ください | 見てください | 資料を下さい（本動詞） |
| いただく | 読んでいただく | お茶を頂く（本動詞） |
| いたす | 対応いたします | |
| こと | 変えること | 大事、仕事 |
| とき | 落ちたとき | 時刻、時間 |
| ため | 確かめるため | 為替 |
| もの | 作ったもの | 物を置く |
| ところ | 直したところ | 場所の意味のところ |
| ほう | 速いほう | 方角、方法 |
| とおり | 書いたとおり | 大通り |
| ほか | そのほか | |
| ごと | トピックごと | |
| など | A や B など | |
| さらに、すでに、すべて、ほとんど、さまざま、ぜひ、あらかじめ、おおむね、かつ、ただし、すなわち、もちろん、たくさん、ちょうど、いったん、めったに、いわゆる、まで | | |
| および、または、ならびに、もしくは | | |

## 言い換え表（翻訳調）

| 翻訳調 | 言い換え |
|---|---|
| 〜することができます | 〜できます |
| 〜を行う（確認を行う） | 〜する（確認する） |
| 〜ということ、〜というもの | 削る |
| 〜において、〜における | 〜で、〜の |
| 〜に関して、〜に関する | 〜について、〜の |
| 〜に対して（対象でないとき） | 〜に |
| 非常に、極めて、大変 | 数字か事実に置き換える。無理なら削る |
| 〜と思われます、〜と考えられます | 〜です。根拠を添える。推測なら「確かめていない」 |
| 〜する必要があります | 〜してください、〜する |
| 〜することが重要です | 〜する。理由を1文 |
| 〜となります、〜になります（変化でないとき） | 〜です |
| 〜させていただきます | 〜します |
| 基本的に、原則として（例外を書かないとき） | 削る |
| 適切に、しっかりと、きちんと | 何をどうするかを書く |
| 様々な、多くの（数を言えるとき） | 数を書く |
| 〜等（など） | など、か、列挙を閉じる |
| まず最初に | まず |
| 〜という形で | 〜で |

## 外国語の文字の混入

日本語の文書に簡体字・繁体字・ハングルが混ざると、読む人には壊れて見える。
`proofread.py` は日本語にない字形だけを拾う（国・学・会・体・点・来は日本語なので拾わない）。

| 混ざりやすい字 | 日本語 |
|---|---|
| 们 这 个 说 对 时 间 为 还 让 过 发 经 现 样 种 开 关 东 车 书 长 实 | 達 これ 個 説 対 時 間 為 還 譲 過 発 経 現 様 種 開 関 東 車 書 長 実 | <!-- ja-proofread: ignore -->
| 們 這 對 說 體 國 學 點 實 關 寫 讀 發 經 樣 當 變 | 達 これ 対 説 体 国 学 点 実 関 写 読 発 経 様 当 変 | <!-- ja-proofread: ignore -->

固有名詞（人名、地名、旧字体の社名）は残す。その行の末尾に `ja-proofread: ignore`（Markdown なら
`<!-- ja-proofread: ignore -->`）を書くと、その行は見ない。報告には「固有名詞」と書く。

## 読み直しの観点と例

| 観点 | 前 | 後 |
|---|---|---|
| 結論の位置 | 調べたところ、いくつかの要因が考えられますが、原因は設定の誤りでした | 原因は設定の誤り。〜 |
| 一文一義 | テストを足したが、直す前のコードで落ちることを確かめ、それから直した | テストを足した。直す前のコードで落ちることを確かめた。それから直した |
| 主語 | 確認して問題なければマージする（誰が?） | CI が通れば、私がマージする |
| 指示語 | その件は保留にした | 著者のメールの件は保留にした |
| カタカナ語 | イシューをフィックスしてデプロイ | 課題を直してデプロイ |
| 箇条書きの形 | ・確認する ・テスト ・マージした | ・確認する ・テストする ・マージする |
| 数字 | 三件のPRをマージ | 3 件の PR をマージ |
| 見出し | 「その他」の下に手順の中核がある | 中核を見出しにする |
| 謝罪 | 大変申し訳ありません。私の確認不足で… | 確かめずに書いた。直した |
