# 直訳の癖と、自然な日本語への直し方

英語で考えた文をそのまま日本語に移すと、意味は通るが読む人が引っかかる。
翻訳ツールの出力と同じ水準を目指すなら、次の癖を直す。各項目は「前」が直訳、「後」が直したもの。

## 文の形

| 癖 | 前 | 後 |
|---|---|---|
| 体言止めの連発 | 検査は通過。マージは完了。次は配布。 | 検査は通りました。マージも終わっています。次は配布です。 |
| 名詞を積む | ユーザー名入りパス検出ルール追加 | ユーザー名が入ったパスを検出するルールを足しました |
| 文末の繰り返し | 直しました。確かめました。送りました。 | 直して確かめたうえで、送りました。 |
| 一文に詰める | 検査を直し、テストを足し、通ることを確かめ、PR にしてマージした。 | 検査を直してテストを足しました。通ることを確かめてから PR にし、マージしました。 |
| 文末の形が揃わない | 直した。確かめています。送ります。 | 直しました。確かめました。送ります。 |

## 主語と述語

| 癖 | 前 | 後 |
|---|---|---|
| 無生物主語 | このスキルは並列開発を可能にします | このスキルを使うと、並列で開発できます |
| 主語が抜けて曖昧 | 確認して問題なければマージする | CI が通れば、私がマージします |
| 受け身の多用 | 設定が変更され、テストが実行され、結果が報告されます | 設定を変えてテストを走らせ、結果を報告します |
| 自動詞と他動詞の取り違え | 設定を直って、テストが通した | 設定を直して、テストが通りました |
| 「〜が行われる」 | 検査が行われます | 検査します |

## 助詞

| 癖 | 前 | 後 |
|---|---|---|
| 助詞を抜く | ブランチ main 移動 完了 | ブランチを main に移しました |
| は と が | 検査は通りましたが、PR は作っていません（対比でないのに は） | 検査が通ったので、PR を作りました |
| に と で | GitHub に確かめた | GitHub で確かめた |
| に と へ | ファイルへ書く | ファイルに書く |
| を の重複 | 設定を変更を行う | 設定を変える |
| の の連続 | Ciel のスキルの配布の仕組みの説明 | Ciel がスキルを配布する仕組みの説明 |

## 語順

| 癖 | 前 | 後 |
|---|---|---|
| 目的を先に置く | 検出を増やすために、ルールを足しました | ルールを足して、検出を増やしました |
| 条件を後ろに置く | PR を作ります、CI が通れば | CI が通れば、PR を作ります |
| 理由を後ろに置く | 止めました。枠が切れたので | 枠が切れたので止めました |
| 修飾が遠い | 昨日直した設定のテストの結果 | 昨日直した設定について、テストの結果 |

## 言い回し

| 直訳 | 自然な言い方 |
|---|---|
| 〜することができます | 〜できます |
| 〜することが可能です | 〜できます |
| 〜を可能にします | 〜できるようにします |
| 〜する必要があります | 〜してください、〜します |
| 〜することが重要です | 〜します。理由を1文 |
| 〜と思われます、〜と考えられます | 〜です。根拠を添える。推測なら「確かめていません」 |
| 〜かもしれません（根拠なし） | 確かめたか、確かめていないかを書く |
| 〜ように見えます | 見たままを書く。「〜でした」 |
| 〜に関して、〜において、〜に対して | 〜について、〜で、〜に |
| 〜という形で、〜という方法で | 〜で |
| 〜となります、〜になります（変化でない） | 〜です |
| 基本的に、原則として（例外を書かない） | 削る |
| 1つの〜、いくつかの〜（冠詞の名残） | 〜、数を書く |
| それ、これ、この件（指示語） | 何を指すかを書く |
| 〜を行う | 〜する |
| 〜させていただきます | 〜します |
| 〜を確認させてください | 〜を確かめます、〜を教えてください |
| お待ちください | 〜が終わったら知らせます |
| 問題ありません | 大丈夫です、そのままで進めます |
| 対応します | 直します、作ります、調べます（何をするかを書く） |
| 実施する | する、行う、走らせる |
| 完了しました | 終わりました、できました |

## 記号で済ませない

| 癖 | 前 | 後 |
|---|---|---|
| 矢印でつなぐ | 指摘 → 閾値 0.8 → 通過率 70% | 指摘を受けて閾値を 0.8 に上げました。通過率は 70% になりました |
| コロンで並べる | 結果: 緑。次: 配布。 | 結果は緑でした。次は配布です。 |
| 読点で語を並べる | 検査、テスト、PR、マージ、完了 | 検査とテストを通し、PR をマージしました |
| 括弧に詰める | マージした（CI 緑、テスト 13 件、validate 0） | マージしました。CI は緑で、テスト 13 件と validate が通っています |
| スラッシュで並べる | 重大 2 / 注意 0 | 重大が 2 件、注意が 0 件 |

表の中では記号でよい。文の中では文にする。

## 会話の返事の形

マーク（★ ↩ ❕ ❔）の後ろは、です・ますの文で書く。1行でも文にする。

| 前 | 後 |
|---|---|
| ★ PR #61: マージ済み。CI 緑。 | ★ PR #61 をマージしました。CI は緑です。 |
| ↩ 範囲と名前: public 限定 → private から | ↩ 範囲と名前について、public 限定だったものを private の段階から見る形に直しました。 |
| ❕ 片付け: Routine 7件 消した | ❕ 片付けとして、実行済みの Routine を 7 件消しました。 |
| ❔ `**` 161 箇所: 文書にも当てるか | ❔ 文書の中の `**` 161 箇所も、応答と同じ決まりで消しますか。 |

## 英語を日本語にするとき

英語の資料や指示を日本語で伝えるときは、語を置き換えるのではなく、意味を日本語で言い直す。

1. 文の意味を取る。誰が何をどうする、の3つに分ける
2. 日本語の語順で組み立てる。条件と理由は先、結論は後。主語は文脈で分かれば省く
3. 用語は `glossary.md` の語。固有名詞、コマンド、設定のキーは原文のまま
4. 英語の文1つを日本語の文1つに対応させない。2つに分けてよいし、2つを1つにしてよい
5. 読み直して、日本語として書いたものに見えるかを見る。見えなければ 1 に戻る

| 英語 | 直訳 | 言い直し |
|---|---|---|
| This skill enables parallel development by splitting sessions per topic. | このスキルはトピックごとにセッションを分けることによって並列開発を可能にします。 | トピックごとにセッションを分けるので、並列で開発できます。 |
| Make sure to run the tests before pushing. | push する前にテストを実行することを確認してください。 | push する前に、テストを走らせてください。 |
| It is recommended that you rotate the key first. | 最初に鍵をローテートすることが推奨されます。 | 先に鍵をローテートしてください。 |
| The check failed because the file was not found. | ファイルが見つからなかったため、チェックは失敗しました。 | ファイルがなかったので、チェックが落ちました。 |
| You might want to consider adding a test. | テストを追加することを検討したいかもしれません。 | テストを足すとよいです。 |
