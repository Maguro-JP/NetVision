# ユーザーの語の対応表

ユーザーが使った語を正とする。私が出しがちな略語・訳語・造語は、左の語に直す。
行はユーザーの発言から足す。`hooks/terms_learn.py` が発言の語を数え、`--candidates` で表に無い語を出す。
ja-proofread の `glossary.md`（開発者の間で通る語の既定）と重なったら、こちらが先。

直す言い方は「、」で区切る。英数字は単語の境界で、カタカナはカタカナの境界で当てるので、
「リポ」は「リポジトリ」に当たらない。正規表現も書ける（`(?<!後)片付け`）。表の区切りと重なるので、正規表現に「|」は書かない。予定の語に見える略語はバッククォートで囲む。
ユーザーの語を、別の行の直す言い方に書かない（`scripts/terms.py --table` が見る）。
