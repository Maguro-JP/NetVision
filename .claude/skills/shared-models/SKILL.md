# 模型は C:\LLM で共有する

ユーザーが決めたこと。模型は数 GB あるので、自作アプリごとに持たず、1 か所で共有する。
置き場の名前は、のちに制作会社・スタジオ名のフォルダにまとめ直すことがある。そのときはこのスキルの道だけを直す。

## 1. 置き場

```
C:\LLM\
  README.txt      この置き場の説明（無ければアプリが作る。あれば書き換えない）
  gguf\           言葉の模型（llama.cpp などで読む .gguf）
  huggingface\    Hugging Face の形のままの模型（画像生成など）。HF の cache_dir としてそのまま渡す
```

- 環境変数 `LLM_HOME` があれば、`C:\LLM` の代わりにそこを使う
- Windows 以外は `LLM_HOME` が無ければ、そのアプリのこれまでの置き場のままでよい
- 道は ASCII だけ。利用者名が全角だと、AppData の道で llama.cpp が模型を開けなかった

## 2. 決まり

- 模型を探すときは、まず `C:\LLM` を見る。前の置き場（アプリごとの models）は読むだけにして、そこへは新しく取らない
- 新しく取る模型は `C:\LLM` に置く。取っている途中は `<名前>.part` に書き、取り終わってから名前を変える
- ほかのアプリが置いた模型を消さない・動かさない・名前を変えない。消すのは、利用者が画面で選んだときだけ
- 取る前に、候補（名前、得意なこと、大きさ）を見せて利用者に選ばせる。すでに `C:\LLM` にある物は「取得済み」と出し、取り直さない
- 模型でない物（設定、記録、動かす部品）は `C:\ProgramData\<アプリ名>` に置く。アプリ本体は `C:\Program Files\<アプリ名>` に置き、書き換えない

## 3. 確かめる

- `LLM_HOME` を一時フォルダに向けた試験で、探す・取る先が `gguf\` と `huggingface\` になることを見る
- すでに置いてある模型を、取り直さずに使えることを見る
