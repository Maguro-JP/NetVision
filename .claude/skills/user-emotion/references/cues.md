# 手がかりの語と、取り込み元の要点

手がかりの語は、このリポジトリのユーザーの発言から取った。別のユーザーなら語が違うので、`terms_learn.py --candidates` と同じ要領で、発言から足す。
`hooks/emotion.py` の `CUES` が本体で、ここはその説明。

## 語の表

| 感情 | 語 | 出どころ |
|---|---|---|
| 怒り | 無能、クソ、ふざけ、ゴミ、最悪、ありえない、信用できない、バカ、馬鹿、アホ、使えない、何回言わせ、いい加減にしろ | 発言と一般の語 |  <!-- content-audit: ignore（検出語の一覧） -->
| いらだち | 何度も、何回も、言わせんな、言わせる、だから、じゃん、じゃねえ、んだよ、だろ?、だぞ、すんな、しろよ、やれよ、とけよ、いい加減、ちゃんと、真面、マジで、無駄、バグ設計、勝手に、反抗、聞いてない、読み解け、理解しろ、考えろ、言ってんじゃん | 発言 |
| 急かし | 早く、まだ?、いつ終わる、遅い、遅すぎ、時間かかりすぎ、待たせ、さっさと、今すぐ | 発言と一般の語 |
| 失望 | またか、また同じ、前も、同じこと、直ってない、変わってない、結局、期待外れ、がっかり | 発言と一般の語 |
| 承認 | 任せる、いいよ、いいぞ、OK、おk、それでいい、よし、助かる、ありがとう、さすが、いいね、進めて、やっていい、頼む | 発言 |

強い順（怒り → いらだち → 急かし → 失望 → 承認）に当て、先に当たったものを感情とする。

## 取り込み元の要点

取り込み元: [Owl-Listener/ai-design-skills](https://github.com/Owl-Listener/ai-design-skills) の frustration-detection（MIT）。出典と取り込み方は docs/SOURCES.md。

- 手がかりは 1 つでは雑音。文字の強さ（大文字、記号の連打）、言い方の短さ、同じことの言い直し、罵りの語、時間の語（今すぐ）、見限りの語（もういい）を、ターンをまたいで積む
- 急ぎと、いらだちは別物。急ぎには速さで答え、調子は変えない
- 同じ問いが 3 回目なら、言い換えて答え直すのではなく、やり方を変える
- 黙って合わせる。感情について書かず、返答の中身（短さ、確かさ、やること）で示す
- 感情を言い当てる、謝罪の定型を重ねる、1 つの手がかりで大げさに共感する、気づいたのに同じやり方を続ける、長い慰めを書く、はしない
- 長い返答のあとの長い沈黙は、立ち去りの印。状態を保存して、戻ってきたときに続きができる形にする

Ciel では、点数の表と人への引き継ぎは取り込まない（相手は 1 人のユーザーで、引き継ぐ先が無い）。
「同じ指示が 2 回目」は、直前 3 つの一言との語の重なりで機械が数える。
