# バグの帳簿

直していないバグと、直した記録です。1 件 1 節で、`.claude/skills/bug-first/scripts/bugs.py` が読み書きします（bug-first）。
重さは 致命的・重い・軽い、状態は 未修正・修正中・確認待ち・修正済み・対象外 です。致命的は、今の作業を止めて修正版を出します。
漏洩のバグでは、漏れた値そのものを書きません。場所と種類だけを書きます。
